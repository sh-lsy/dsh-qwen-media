# 提示词工程指南（ distilled from 官方 Prompt 指南与模型文档）

## 图像

- 基础：主体 + 场景 + 风格 + 构图/光影。描述越具体越稳。
- 文字渲染/海报/图表/UI（qwen-image-3.0-pro 强项）：把要出现的文字用引号逐字写出，说明字号层级与位置，如"标题'夏日特惠'居中、副标题小字居下"。
- 编辑指令（I2I）：直接说改什么、保留什么，如"把背景换成海边黄昏，人物与服装保持不变"。多图时按顺序指代"图1/图2"。
- 组图（wan2.7 `--sequential`）：在 prompt 中按"第一张…第二张…"列出每张内容，保持主体/风格统一的总述在前。
- 反向提示词（仅 qwen）：`--negative "低分辨率、模糊、多余的手指、文字错乱"`。
- 简单提示词可依赖 prompt_extend（默认开）；需要精确控制时 `--no-extend`。
- 长度：qwen 建议 ≤4500 Token；wan text ≤5000 字符。

## 视频

- 基础公式：**主体 + 场景 + 运动**。运动写清动作过程与镜头运动（"镜头缓慢推进""固定镜头"）。
- 多镜头（wan3.0/wan2.7）：`总体描述 + 镜头序号 + 时间戳 + 分镜内容`，如"镜头1[0-3秒] 全景：雨夜街头；镜头2[3-6秒] 特写：…"。想要单镜头就写"生成单镜头视频"。
- 声音公式（原生音频模型）：主体+场景+运动+**声音描述**。人声=台词+情绪+语调+语速+音色；音效=动作对应声；BGM=风格。例："他压低声音说：'别出声'，远处雷声渐近，悬疑弦乐铺底"。
- 口型同步：wan3.0 传 `--audio-url`（wav/mp3、2–30s、≤15MB）；音频长于 duration 截断、短于则后段无声。
- 参考生视频：
  - happyhorse-r2v：`[Image 1] 中身着红旗袍的女性走进 [Image 2] 的房间，回头微笑说："你来了。"`（顺序=--ref 顺序）
  - wan：`图 1 的猫在图 2 的房间里玩耍`（英文 `Image 1`/`Video 1`，空格分隔）；音色参考用参考视频。
- 首帧生视频（i2v）：prompt 描述"动起来之后"的运动与声音，不要复述首帧静态内容。
- 反向提示词（仅 wan3.0）：`--negative "低分辨率、错误、最差质量、残缺、多余的手指、比例不良"`（≤500字符）。
- 长度：happyhorse ≤2500 中文字符；超出自动截断。

## 参考图保真（r2v / i2v / 图像编辑）

- **特征锁**：逐条枚举判别特征——品种、瞳色、斑纹位置（如"左眼上方灰色斑块"）、毛色分布、尾巴渐变、鼻色、毛量蓬松度；并加一致性指令："保持与参考图完全一致的毛色分布与面部斑纹，不得改变品种、瞳色、斑纹位置"。
- **画风锁**：先识别参考图画风（软萌插画/写实摄影/3D 渲染），在 prompt 显式锁定（"与参考图一致的软萌治愈插画风、线条干净"），除非用户另指定。画风不锁是参考视频"长得不像"的主因之一。
- **关闭智能改写**：参考任务默认 `--no-extend`（prompt_extend=false），避免改写稀释参考绑定；脚本在有参考输入时自动关闭，显式 `--extend` 才开。纯 t2v 短 prompt 仍默认开。
- **反向提示词（仅 wan3.0）**：`--negative "毛色改变、斑纹位置错误、瞳色改变、画风突变、多余肢体"`。
- **干净单主体参考**：参考图是多面板设定表/复杂场景时，先做立绘预处理——qwen-image-3.0-pro I2I（1 ref）："提取并重绘为单一角色立绘：正面全身、纯色背景、保持参考图的斑纹/瞳色/画风、无文字无面板边框"；再用立绘作 r2v/i2v 参考。多面板直接喂视频模型会被平均化/误读。
- **高保真双锁（wan3.0）**：`--first-frame 立绘 --ref 立绘`（官方支持首帧+主体参考联合控制一致性）；注意有首帧时 ratio 跟随首帧。
- **指代规范**：happyhorse-r2v 用 `[Image 1]…[Image 9]`（顺序=--ref 顺序）；wan 用 `图 1/视频 1` 或 `Image 1/Video 1`。指代后补主体说明（"[Image 1] 中身着红旗袍的女性"）。
- **运动与参考分离**：prompt 只描述"动起来之后"的运动/镜头/声音，不复述参考图静态布局，避免模型把设定表排版当画面。

### 示例：设定表布偶猫 → 月面漫步（保真重写版）

> [Image 1] 中的布偶猫角色，保持与参考图完全一致：蓝色大而圆的眼睛、左眼上方灰色斑块、浅灰色耳朵与脸部点缀、粉色鼻子、蓬松奶白色长毛、灰色渐变尾巴；不得改变品种、瞳色、斑纹位置与毛色分布。画风锁定为与参考图一致的软萌治愈插画风、线条干净。它穿着合身的白色宇航服、头戴透明圆形头盔，在月球表面缓慢漫步：低重力下步伐轻柔弹跳，月壤扬起细尘并留下脚印；背景漆黑星空与悬挂的蓝色地球，侧逆光勾勒毛发轮廓。镜头缓慢侧向跟随，生成单镜头视频。声音：轻柔治愈钢琴 BGM、脚步踩月壤沙沙声、头盔内轻微呼吸声。

配合 `--no-extend`（自动）；若用 wan3.0 再加 `--negative "毛色改变、斑纹位置错误、瞳色改变、画风突变、多余肢体"`。

## 审核拦截改写

触发 DataInspectionFailed 等审核错误时：去除真实人名/品牌/暴力/敏感意象，改用泛化描述（"一位穿红裙的舞者"而非真实明星），重试一次；仍失败则如实报告并建议换主题。

## 成本提示措辞

视频按秒×分辨率计费：向用户确认时给出"模型 / 分辨率 / 秒数"三要素，如"wan3.0-video / 1080P / 15s（约为 720P/5s 的 6 倍像素秒）"。失败任务不计费。
